# Personal Agent Skills

A personal collection of reusable Agent Skills, continuously refined through real-world practice.

## Goals

- Improve the quality, reliability, and efficiency of AI agents.
- Reuse proven skills and best practices from the open-source community.
- Develop and refine personal workflows through practical experience.
- Keep skills portable across different agent frameworks and LLMs.

## Organization

- `skills/dev/` — Software engineering skills, including code understanding, design, implementation, review, testing, and deployment.
- `skills/research/` — Research and learning skills.
- `skills/gaming/` - AI gaming skills, including game agents, reinforcement learning, and evaluation.
- `skills/creative/` - AI creative generation skills, including game concepts, advertising creatives, and content generation.

## Principles

- **Practice first** — Introduce skills based on real needs.
- **Reuse before reinventing** — Prefer proven open-source solutions.
- **Evidence-driven** — Evaluate effectiveness before adopting changes.
- **Keep it simple** — Avoid unnecessary abstractions and complexity.

Skills will be added incrementally as practical needs emerge.
